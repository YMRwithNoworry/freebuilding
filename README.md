# FreeBuilding

完整功能说明见 [FEATURES.md](FEATURES.md)。

Minecraft **1.20.1 Forge** 城市建造模组。用城市法杖框选任意 3D 区域，保存为建筑预设，再通过可视化城市规划器把预设作为“失落的城市”式城市建筑随机生成；同时支持自动世界生成、俯视预览图和预览图导出。

## 功能

- **3D 区域选取**
  - 城市法杖右键设置点 1，左键设置点 2；Shift+右键或右键空气取消当前选区。
  - 客户端绘制高亮线框、半透明面，并在左上角显示坐标和体积。
  - 选区会按玩家在服务器运行期间同步；服务器关闭前会清理未保存的临时选区，避免退出世界时阻塞保存。
- **建筑预设**
  - `/fb save <名称>` 把选区保存为 `StructureTemplate` NBT，同时生成带格式版本的 `.fbp` 可移植文件。
  - 预设文件位于 `.minecraft/config/freebuilding/presets/`，所有存档共享；旧存档中的 `<存档>/freebuilding/presets/` 会在首次启动时自动迁移。
  - `/fb list`、`/fb delete`、`/fb reload`、`/fb export <名称>`、`/fb import preset <文件> [force]`。
  - `.fbp` 文件可以复制到另一份实例的 `config/freebuilding/imports/` 后导入，也可以直接放入 `presets/`。
  - 默认限制：单轴 ≤ 64 格，总体积 ≤ 110,592 格（可在 `config/freebuilding-common.toml` 调整）。
- **城市规划 GUI**
  - `/fb gui` 或使用“城市规划器”物品打开。
  - 预设列表、权重滑条、启用/禁用、删除。
  - 城市样式：现代 / 废墟 / 工业 / 自然。
  - 地块大小、道路宽度、城市规模、位置抖动、废墟率、路灯率、公园率、旋转模式、城市种子。
  - 保存预设时如果建筑大于当前地块，会自动扩大地块；列表中的 `!` 表示该预设仍大于当前地块，可在“布局”页点击“适配最大预设”。
  - 自动世界生成开关与概率。
  - 俯视城市预览：手动城市 / 自动城市示例。
  - “保存预览图”写入 `.minecraft/screenshots/freebuilding_preview_<时间>.png`。
- **按需生成城市**
  - GUI 中确认后在玩家附近逐 tick 生成。
  - 包含地形平整、地基、道路、人行道、路灯、公园、建筑、废墟装饰。
  - 生成前会二次确认；生成不可撤销。
- **自动世界生成**
  - 主世界按固定 256×256 城市单元随机生成城市。
  - 每个区块独立生成自己的切片，支持跨区块建筑。
  - 使用玩家保存的预设与权重；没有可用预设时使用内置程序化建筑。
  - 默认概率 25%，可在 GUI 调整；只影响新生成的区块。
- **乡村 / 荒地生成**
  - 城市单元之外的陆地按 128×128 乡村单元生成独栋房屋或 3×3 小型村庄。
  - 村庄包含土径、房屋、农场/水井、栅栏和路灯；沙漠/恶地使用荒地材质与干枯花园。
  - 跳过海洋/河流/沙滩、与城市单元重叠的区域，以及中心已有原版村庄的位置。
  - GUI“乡村”页可开关、选择独栋/村庄/混合、调整概率和乡村地块大小。
  - 只影响新生成的区块。
- **预览图导出**
  - `/fb city preview` 将当前手动城市布局导出到 `<存档>/freebuilding/preview-export.png`（需要权限等级 2）。
- **失落的城市（The Lost Cities）兼容**
  - 安装 Lost Cities 1.20.1 Forge 后，其单栋建筑会转换为 `lc_<建筑名>` 预设，写入共享预设库，可用于本模组的手动城市、自动城市和新世界全地图城市生成。
  - 两种世界生成会按 256×256 城市单元互斥：启用 FreeBuilding 城市的单元由 FreeBuilding 接管，Lost Cities 会跳过其城市建筑；其他单元保留 Lost Cities 原生城市生成。
  - 乡村站点也会查询 Lost Cities 城市地图，避免在 Lost Cities 城区中心生成乡村建筑。
  - 该互斥使用 Lost Cities 运行时 API 反射接入，不增加编译期依赖；未安装 Lost Cities 时不会改变 FreeBuilding 行为。
  - 打开原版“创建新世界”界面中的“自由建筑预设”按钮，可以选择要参与生成的预设；默认覆盖率为 100%，即所有符合地形条件的新陆地区块都生成城市。
  - 在创建世界前打开该页面时，如果 Lost Cities 已安装，会先把其资源缓存到共享库，因此可以直接勾选 Lost Cities 城市建筑。
  - 导入的预设默认权重 5、启用；可在 GUI 中像普通预设一样调整权重/禁用/删除。
  - GUI“世界”页新增“导入失落的城市”按钮；也可使用 `/fb import lostcities [force]` 手动导入或强制刷新。
  - 转换时会选择代表性的地面/楼层/屋顶部件，并使用 Lost Cities 标准调色板；不导入多建筑组合（multibuildings）、地下室和 `parts2` 内部部件。

## 环境

- Minecraft 1.20.1
- Forge 47.4.28
- Java 17
- 可选：The Lost Cities 1.20.1 Forge（用于导入其建筑预设）

## 构建

```bash
export JAVA_HOME="/path/to/jdk-17"
./gradlew build
```

产物：`build/libs/freebuilding-1.3.2+1.20.1.jar`

Windows 示例：

```bash
export JAVA_HOME="D:/MC/jdk/graalvm-community-openjdk-17.0.9+9.1"
./gradlew build
```

## 快速开始

1. 创造模式物品栏“自由建筑”页签获取 **城市法杖** 和 **城市规划器**，或使用 `/fb wand`、`/fb planner`。
2. 用法杖右键一个方块设置点 1，左键方块设置点 2；Shift+右键或右键空气可取消选区。
3. 执行 `/fb save my_house` 保存建筑预设。
4. 执行 `/fb gui` 或右键城市规划器打开 GUI。
5. 在“建筑”页调整预设权重/启用状态；在“布局”“装饰”“世界”“乡村”页调整城市样式和乡村生成。
6. 创建新世界时，点击“自由建筑预设”，选择 Lost Cities 或其他共享预设，并保持“在所有可生成陆地生成城市”开启，即可让新世界按所选预设覆盖生成城市。
7. 右侧查看俯视预览，点击“生成城市”，确认后生成。
8. 自动世界生成默认开启；用 `/fb city locate` 查找最近的自动城市中心，然后前往该处（只对新区块生效）。

## 指令

| 指令 | 权限 | 说明 |
|---|---|---|
| `/fb wand` | 2 | 获得城市法杖 |
| `/fb planner` | 2 | 获得城市规划器 |
| `/fb pos1` / `/fb pos2` | 0 | 用视线目标方块设置选区点 |
| `/fb clear` | 0 | 清空选区 |
| `/fb save <名称> [force]` | 2 | 保存选区为建筑预设 |
| `/fb delete <名称>` | 2 | 删除建筑预设 |
| `/fb list` | 0 | 列出预设、尺寸与权重 |
| `/fb reload` | 2 | 从磁盘重新加载配置与预设 |
| `/fb export <名称>` | 2 | 导出共享预设为可移植 `.fbp` 文件 |
| `/fb import preset <文件> [force]` | 2 | 从 `config/freebuilding/imports/` 或 `exports/` 导入 `.fbp` 文件 |
| `/fb import lostcities` | 2 | 导入缺失的失落的城市建筑预设 |
| `/fb import lostcities force` | 2 | 强制重新转换并覆盖所有失落的城市预设 |
| `/fb gui` | 2 | 打开城市规划 GUI（规划器物品同样需要权限等级 2） |
| `/fb city build` | 0 | 显示本次城市生成范围 |
| `/fb city build confirm` | 2 | 在玩家位置生成城市 |
| `/fb city locate` | 0 | 查找最近的自动城市中心 |
| `/fb city preview` | 2 | 导出当前手动城市俯视图 |
| `/fb demo` | 2 | 在玩家前方生成示例小屋并保存为 `demo_house` |

## 城市样式

| 样式 | 道路 | 地块 | 特点 |
|---|---|---|---|
| 现代 | 灰色混凝土 | 平滑石 | 灯笼路灯、灰色调街区 |
| 废墟 | 沙砾 | 圆石 | 更高废墟率、苔石地基 |
| 工业 | 抛光黑石 | 抛光深板岩 | 海晶灯、铁栏杆 |
| 自然 | 土径 | 草方块 | 苔藓、橡木路灯、更多绿化 |

## 数据文件

```
<存档>/freebuilding/
  config.json              # 当前存档的城市/乡村布局、样式、权重、生成概率
  preview-export.png       # /fb city preview 导出
  lostcities_imported.marker # 当前存档的失落的城市导入标记

.minecraft/config/freebuilding/
  presets/
    my_house.nbt           # 共享标准结构文件
    my_house.fbp           # 共享可移植文件
    lc_building1.fbp       # 失落的城市可移植预设
  imports/                 # 放入外部 .fbp 后用 /fb import preset 导入
  exports/                 # /fb export 输出目录
```

## 已知限制

- 按需生成会清除城市范围内的方块，**没有撤销**。
- 建筑预设只保存方块，不保存实体（避免把玩家/生物复制进建筑）。
- 自动世界生成中的方块实体（箱子等）尽力恢复，失败时保留空方块。
- 自动城市只影响新生成的区块；已经生成的区块不会补城市。
- 出生点区块可能在模组世界数据初始化前生成，因此出生点附近不保证有自动城市；向远处探索即可。
- 海洋单元会跳过；高山会被削平，边缘可能留下山体。
- 从创建世界界面选择的城市设置只在新存档首次启动时应用，之后由该存档自己的 `config.json` 管理。
- 创建世界界面的“全地图”指所有符合地形条件、且尚未生成的陆地区块；海洋等无法平整的区域仍会跳过，已经生成的区块不会补城市。
- `.fbp` 是带 `format` 版本号的文本 JSON，内部封装标准压缩结构 NBT；可跨存档、跨世界复制，也可在其他 FreeBuilding 版本中导入。
- 跨 Minecraft 版本使用时，只有目标版本仍存在的方块、方块状态和方块实体数据能完整恢复；已删除或改名的方块会由 Minecraft 的结构加载器按目标版本处理，不能保证完全一致。
- 乡村站点默认使用 128×128 单元；城市单元内不会生成乡村，避免两套建筑重叠。
- 乡村只检查中心点是否有原版村庄；如果原版村庄偏离中心，仍可能与乡村站点局部重叠。
- 乡村生成也只影响新区块；已生成区域不会补房屋或村庄。
- 地块必须能容纳预设的宽度/深度；保存时通常会自动适配，也可手动调整。若预设尺寸超过 64 格上限，需要增大 `maxSelectionDimension` 并调整地块（当前 GUI 上限为 64）。
- 失落的城市导入是“代表性建筑”转换，不是完整复刻其随机楼层/损坏/地下室/内部 `parts2`；箱子、刷怪笼等方块实体数据可能不完整。
- 失落的城市多建筑组合（医院、购物中心、市政厅等 `multibuildings`）不会作为单个巨型预设导入；它们引用的单栋建筑仍会出现在预设列表中。
- 如果两个模组同时启用世界生成，已经生成的旧区块不会重新整理；互斥规则只对新生成区块生效。新区域会按城市单元由 FreeBuilding 或 Lost Cities 其中一方负责，避免两套城市重叠。
